## Agentic Fitness App POC 

Outlining an agentic fitness bot using LangGraph, LangSmith, and Cognee RAG DB. The bot can take in fitness data such as unstructured notes and then provide analysis on the data itself 
to provide better workout insights based on notes per workout, the actual workout data (weight, sets, etc.) and sleep data from devices like Whoop for a 360 degree view of insights 
for the serious workout professional.
